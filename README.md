# Roolean

A proof checker for the Roole solver of Satisfiability Modulo Theories (SMT) problems.

Roolean is written in the Lean programming language.
The idea is to have Roole do the solving and Roolean validate the correctness of the solution
by performing evaluations and transformations on the problem that are proven within Lean
to be sound.

Under construction.
